# AI + Facebook Page Growth — Webinar Landing Page

Responsive landing page ready for GitHub Pages.

## Registration
The **Register / Pay ₹99** buttons are configured to open the Razorpay payment page.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `webinar-poster.png`, and `trainer.png`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and open the GitHub Pages URL provided by GitHub.
